# 7. Information Architecture

## Purpose
The Information Architecture defines how knowledge is organized, secured, discovered and reused throughout Policy Brain.

## Core Hierarchy
Organization
- Folders (security boundary)
- Tags (classification)
- Policies
- Rules
- Rule Versions
- Knowledge Objects

## Principles
- Folder-based RBAC
- Tags without security semantics
- Immutable version history
- Knowledge-first organization
- Tenant isolation

## Navigation
Users primarily navigate through folders, while search provides cross-folder discovery based on permissions.

## Metadata
Every major entity carries standardized metadata including owner, timestamps, version, status, tags and audit references.
