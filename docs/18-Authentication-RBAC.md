# 18. Authentication & RBAC

## Purpose
Authentication verifies user identity and RBAC controls what each user can access and do.

## Authentication Methods
- Microsoft OAuth
- Google OAuth
- Email/password
- MFA

## Authorization Model
Access is evaluated at organization, folder, policy, rule and capability levels.

## Folder Security
Folders are security boundaries. A user cannot access a folder or its contents without explicit permission.

## Capabilities
- Create policy
- Edit rule
- Review draft
- Approve production
- Export code
- Manage users
- Configure AI

## Principles
- Least privilege
- Deny by default
- Explicit grants
- Tenant isolation
- Audit every security decision
