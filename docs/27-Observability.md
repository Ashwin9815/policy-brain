# 27. Observability

## Purpose
Observability provides visibility into workflow execution, AI behavior, service health and system performance.

## Signals
- Logs
- Metrics
- Traces
- Events
- AI telemetry

## Flight Recorder
Each workflow stage records start time, end time, status, retries, model used, prompt version, token usage and outcome.

## Dashboards
Dashboards show health for workflows, services, integrations, search and AI usage.

## Principles
- Everything is traceable.
- Every failure is diagnosable.
- Sensitive data is redacted.
- Operational history is replayable.

## Alerts
Alerts fire for failures, latency spikes, budget overruns and integration outages.
