# 6. User Journeys

## Purpose
This section describes the primary end-to-end workflows supported by Policy Brain.

## Journey 1: Generate a Policy
1. Upload source documents.
2. AI extracts knowledge objects.
3. User answers clarification questions.
4. Multi-agent workflow generates draft rules.
5. User reviews, edits and approves.
6. Policy is versioned and published.

## Journey 2: Compare Policies
- Select two rules or versions.
- AI highlights additions, removals and conflicts.
- User reviews downstream impacts.

## Journey 3: Collaborate
- Share folder or policy.
- Mention reviewers.
- Resolve comments.
- Complete approval workflow.

## Journey 4: Export
- Choose target format.
- Validate rule.
- Generate executable output.
- Record audit trail and export history.
